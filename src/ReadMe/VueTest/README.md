## VueTest（页面测试说明目录）

本目录用于存放“页面级”的测试说明文档（以页面为单位组织），便于对照接口文档进行前端联调与验收。

目录结构约定：

- `login/`：登录页测试
- `register/`：注册页测试
- `main/`：主页测试
- `user-edit/`：个人主页编辑页测试
- `user-display/`：个人主页展示页测试
- `admin/`：管理员后台页测试
- `activity/`：活动页面测试（创建/浏览/点赞/评论/审核）

每个页面文件夹内包含：

- `README.md`：该页面的访问 URL、关联接口、手工测试步骤、预期结果
