# 项目测试文档

## 一、已实现功能测试

### 1. 个人主页展示和作品编辑功能
- **功能描述**：用户可以在个人主页查看自己的作品，并对作品进行编辑
- **测试方法**：访问用户编辑页面，查看作品列表，点击编辑按钮修改作品信息
- **预期结果**：作品列表正常显示，编辑功能正常工作

### 2. 活动ID关联功能
- **功能描述**：用户可以在作品编辑页面关联活动ID，点击"+"按钮添加新的活动ID输入框
- **测试方法**：在作品编辑页面输入活动ID，点击"+"按钮添加新的输入框
- **预期结果**："+"按钮正常工作，新的活动ID输入框正确显示

### 3. 日期选择器功能
- **功能描述**：用户可以点击日期输入框的任意位置打开日历选择器
- **测试方法**：点击日期输入框的任意位置，查看日历选择器是否弹出
- **预期结果**：日历选择器正常弹出，用户可以选择日期

### 4. 活动排序功能
- **功能描述**：用户可以按最新、最热等条件排序活动
- **测试方法**：在活动列表页面选择排序条件，查看活动列表是否按条件排序
- **预期结果**：活动列表按选择的条件正确排序

### 5. 广场页面作品展示功能
- **功能描述**：广场页面显示所有公开的作品
- **测试方法**：访问广场页面，查看作品列表是否正常显示
- **预期结果**：作品列表正常显示，包含所有公开的作品

### 6. 管理员作品审核功能
- **功能描述**：管理员可以查看待审核的作品，并进行审核操作
- **测试方法**：访问管理员审核页面，查看待审核作品列表，进行审核操作
- **预期结果**：待审核作品列表正常显示，审核操作正常工作

### 7. 管理员公告编辑功能
- **功能描述**：管理员可以编辑公告信息
- **测试方法**：访问管理员公告编辑页面，修改公告信息，保存修改
- **预期结果**：公告信息正常修改，保存成功

### 8. 评论和点赞展示功能
- **功能描述**：在活动和作品详情页面显示评论和点赞数量
- **测试方法**：访问活动和作品详情页面，查看评论和点赞数量是否正常显示
- **预期结果**：评论和点赞数量正常显示
