# PWPS 公益摄影交流平台

## 项目概述

PWPS（Public Welfare Photography Platform）是一个基于 Spring Boot + Vue 3 技术栈构建的公益摄影作品分享与交流平台。该项目旨在为摄影爱好者提供一个展示作品、参与活动、互动交流的社区平台，同时支持公益活动的组织和推广。

## 技术架构

### 后端技术栈
- **框架**: Spring Boot 4.0.3
- **ORM**: MyBatis 3.0.3
- **数据库**: MySQL 8.0+
- **构建工具**: Maven
- **JDK 版本**: Java 17

### 前端技术栈
- **框架**: Vue 3
- **HTTP 客户端**: Axios
- **样式**: 原生 CSS

### 核心功能模块

#### 用户管理
- 用户注册与登录
- 个人信息编辑
- 头像上传与管理
- 积分系统
- 权限分级（管理员/普通用户/游客）

#### 作品管理
- 摄影作品上传
- 作品标签分类（自然、人像、建筑等10类）
- 作品详情展示
- 作品搜索与筛选
- 作品点赞与评论

#### 活动管理
- 活动创建与编辑
- 活动分类（官方活动/个人活动/相册集）
- 活动封面展示
- 活动时间管理
- 活动点赞与评论
- 作品与活动关联

#### 互动功能
- 作品/活动点赞
- 评论系统
- 评论列表展示
- 用户个人主页

#### 管理员功能
- 作品审核管理
- 活动审核管理
- 用户账号管理（封禁、权限修改）
- 评论管理
- 公告发布与管理
- 图片扫描与清理

## 系统架构

项目采用经典的分层架构设计：

- **Controller 层**: 处理 HTTP 请求，提供 RESTful API 接口
- **Service 层**: 实现业务逻辑，处理核心功能
- **Mapper 层**: 数据访问层，通过 MyBatis 与数据库交互
- **Entity 层**: 数据库实体映射
- **DTO 层**: 数据传输对象，用于前后端数据交互

## 数据库设计

系统包含以下核心数据表：
- `user`: 用户信息表
- `uphoto`: 摄影作品表
- `uphoto_detail`: 作品点赞与评论表
- `activity`: 活动表
- `activity_detail`: 活动点赞与评论表
- `announcement`: 公告表
- `point_log`: 积分日志表

## 项目特点

1. **前后端分离**: 前端使用 Vue 3 单页应用，后端提供 RESTful API
2. **权限控制**: 完善的三级权限体系（管理员/普通用户/游客）
3. **内容审核**: 作品和活动需要管理员审核后才能公开显示
4. **图片管理**: 支持图片上传、存储、清理功能
5. **响应式设计**: 前端页面适配不同屏幕尺寸
